# AutoDeck — preview

A live example of the kind of interactive deck AutoDeck produces from a survey file.

**→ https://ackleycb.github.io/autodeck-preview/**

Every number on every slide is computed by one function with a single source of
truth, and the same code path produces the chart, the table and the workbook —
so a figure cannot differ between them.

Try it: click the crosstab tabs above each chart (Overall / Tenure / Paid /
Device / Role) and the Chart/Table toggle. On a phone the deck becomes a
scrolling document rather than a shrunken slide.

### This is synthetic

The survey behind it is generated — 240 fictional newsletter subscribers. No real
respondent data, no client data. The headlines and takeaways were written by hand;
AutoDeck does not invent prose or numbers.

### Not the source

This repository contains only the built HTML. The source is private.
